# 소비기록 화면은 Supabase를 조회하지 않고 전 사용자에게 동일한 정적 mock 데이터를 보여준다

이 화면은 다른 화면들과 달리 실제 `worries` 데이터를 전혀 조회하지 않는다. 로그인한 사용자가 누구든, 실제 보유한 고민 기록이 몇 건이든 상관없이 기간 드롭다운 4개 값 각각에 대응하는 고정된 예시 데이터셋(`src/mocks/records.ts`)을 그대로 보여준다.

1차 구현 중에는 이를 "실데이터 조회 + `abandoned`/`purchased` 확정 로직 부재를 개발 DB 시드로 메꾸는" 방식으로 만들었으나(`docs/adr/0001-spending-record-excludes-outcome-confirmation.md` 참고), 사용자가 원래 의도한 건 화면 전체를 정적 예시로 보여주는 것이었다. 확정 로직도 없고 실사용 서비스도 아닌 프로토타입 단계에서, 사용자별 실데이터를 흉내 내려고 원격 Supabase 프로젝트에 테스트 계정과 더미 row를 심는 것보다 정적 데이터가 훨씬 단순하고 목적(예시 시연)에 그대로 부합한다.
