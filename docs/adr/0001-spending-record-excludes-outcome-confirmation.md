# 소비기록 화면은 상태 확정(포기/구매) 로직을 포함하지 않는다

`ongoing → abandoned/purchased` 전환(확정) 로직과 그 트리거 UI는 코드 전체에 존재하지 않는다. 소비기록 화면 이슈에서 함께 만들 수도 있었지만, 이 확정 UI가 자연스럽게 속하는 자리는 "고민 목록" 화면(타이머가 진행 중인 개별 고민을 다루는 화면)이라고 판단해 이번 스코프에서 제외하고 향후 "고민 목록" 이슈의 의존성으로만 남긴다.

결과적으로 확정 로직이 생기기 전까지는 소비기록 대시보드가 실제 데이터로는 항상 비어 보인다 — 이 문제는 DB 시드가 아니라 화면 자체를 정적 mock 데이터로 만드는 방식으로 해결했다(`docs/adr/0003-spending-record-fully-static-mock.md` 참고).
